### Targets for Week 1

The main goal of this week was to build foundational knowledge about AWS, establish our working environment, and grasp the basics of user administration and cost tracking. The primary targets were:

- **Grasp AWS Basics**:
  - Discover the mechanics of AWS and different cloud computing patterns.
  - Review essential AWS offerings like EC2, S3, IAM, and VPC.

- **Explore the Lab Setup**:
  - Get a clear picture of the lab layout.
  - Master the workflow for practical, hands-on exercises.

- **Group Building**:
  - Assemble our working group.
  - Connect with fellow team members to foster better cooperation.

- **AWS Account Initialization**:
  - Register a fresh Free Tier AWS account.
  - Activate **MFA for the Root Account** to enhance security.
  - Establish an Administrative IAM User.
  - Set up an Admin Group with proper policies.
  - Navigate through the AWS Management Console interface.

- **Budgeting & Expense Tracking**:
  - Formulate a Cost Budget.
  - Set up a Usage Budget.
  - Define Reservation and Savings Plans Budgets.
  - Implement billing alarms.
  - Terminate unused resources.

### Results of Week 1

#### Milestones Reached

- Developed a strong baseline understanding of **AWS core concepts**.
- Acquired the necessary skills to navigate and execute **practical labs**.
- Formalized our **study group** and initiated active collaboration.
- Registered an AWS account equipped with **Free Tier benefits (around $100)**.
- Secured the environment by enabling **Root User MFA**.
- Set up a primary **IAM Administrative User**.
- Gained comfort navigating the **AWS Management Console**.
- Established **AWS Budgets** to monitor platform spending.
- Activated **billing alerts** and performed necessary resource cleanup.

#### Key Takeaways

- **Security Posture**:
  - Refrain from using the Root Account for daily operations.
  - Ensure MFA is enabled across all privileged accounts.

- **Expense Control**:
  - Continuously monitor resource consumption using AWS Budgets.
  - Define strict alerting thresholds to prevent overspending.

- **Optimal Learning**:
  - Engage heavily in hands-on practice.
  - Maintain active communication with the team.
